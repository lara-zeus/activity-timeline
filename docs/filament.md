# Zeus Activity Timeline

Add timelines to custom pages or infolist entries effortlessly. Plus, it teams up smoothly with Spatie Activitylog for easy tracking.

## Features

- 🔥 Add timelines to custom pages.
- 🔥 Add timelines to Filament infolist entries.
- 🔥 Works smoothly with Spatie Activitylog.
